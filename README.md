# CodeAlpha Language Translation Tool

A responsive Language Translation Tool developed as **Task 1** during the **CodeAlpha AI Internship**. The application allows users to translate text between multiple languages using the MyMemory Translation API through a clean and user-friendly interface.

## Features

- Supports 18+ languages
- Automatic language detection
- Text-to-Speech
- Copy translated text
- Swap source and target languages
- Dark and Light mode
- Fully responsive design

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- MyMemory Translation API
